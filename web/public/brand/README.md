### Usage rules

- Do not alter the mark proportions, letter spacing, or icon geometry.
- Prefer the black logo on light / off-white backgrounds.
- Keep stacked icon + wordmark composition when using the full mark.
- App code should load the mark only via `src/lib/brand.ts` and `MirusLogo`.
- Production header / footer: apply after design approval (mock first).
