# MIRUS Brand Assets

## Logo

| File | Purpose |
|------|---------|
| `mirus-logo-original.jpg` | Source file as provided (do not edit design) |
| `mirus-logo.png` | Transparent PNG for site use (white background removed only) |
| `mirus-m-mark.png` | M symbol only (cropped from official art; geometry unchanged) |
| `mirus-m-mark-2x.png` | Higher-res M mark for scroll-scale / mask use |

### Usage rules

- Do not alter the mark proportions, letter spacing, or icon geometry.
- Prefer the black logo on light / off-white backgrounds.
- Keep stacked icon + wordmark composition when using the full mark.
- App code should load the mark only via `src/lib/brand.ts` and `MirusLogo`.
- Production header / footer: apply after design approval (mock first).
